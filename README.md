# Inbasekaran S. — Interactive Portfolio

> AI developer · systems engineer · full-stack builder

A dark, editorial portfolio experience for **Inbasekaran S.** The site combines a technical visual language with human-centered storytelling: a 3D signal orb, floating action controls, project case notes, animated ambient nodes, responsive layouts, and a clear contact path.

## Preview

The project is a static site and can be served by any static hosting provider. Run it locally with:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Then open [http://localhost:4173](http://localhost:4173).

## What is inside

- **3D hero system** — CSS perspective, orbital rings, floating data cards, animated core, and pointer tilt.
- **Ambient signal field** — a lightweight canvas network of particles, connections, and pointer glow.
- **Build method section** — three process cards, layered cards, technical grid surface, orbit accents, and floating quick-navigation actions.
- **Project gallery** — six projects from healthcare, supply chain, operations, product, and algorithms.
- **Case notes modal** — project briefs, build notes, takeaways, technology tags, and repository links without leaving the page.
- **Stack section** — grouped tools across languages, intelligence, interfaces, infrastructure, and data/trust.
- **Responsive navigation** — mobile menu, section-aware desktop navigation, scroll progress, and smooth anchor navigation.
- **Accessible motion** — reduced-motion support, semantic landmarks, keyboard-close modal behavior, and descriptive labels.

## Tech used

- HTML5 and semantic page structure
- Modern CSS with custom properties, CSS gradients, perspective transforms, 3D tilt, responsive media queries, and reduced-motion rules
- Vanilla JavaScript for canvas animation, project filters, intersection-observer reveals, navigation state, modal case notes, clipboard actions, and scroll progress
- Google Fonts with system fallbacks: Space Grotesk, DM Sans, DM Mono, and Playfair Display

No framework or build step is required.

## Customize the portfolio

1. Update the identity, copy, social links, and email in `index.html`.
2. Edit the project cards and matching entries in `projectDetails` inside `script.js`.
3. Change the visual tokens in `:root` inside `styles.css` to retheme the experience.
4. Replace the project repository URLs with your latest links.
5. Keep the `prefers-reduced-motion` styles when adding new animation.

## Deploy

Because this is a static site, it works with GitHub Pages, Netlify, Vercel static hosting, Cloudflare Pages, or any standard web server.

For GitHub Pages:

1. Open the repository's **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose the branch and the root folder `/`.
4. Save and wait for the Pages URL to become available.
